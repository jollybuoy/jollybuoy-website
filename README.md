# JollyBuoy.com

Company website for **JollyBuoy Technology Services Inc.** — Ideas · Code · Impact.

## Stack

- Vite + React + TypeScript
- React Router
- Three.js (hero torus)
- Netlify (hosting + forms)

## Local

```bash
npm install
npm run dev
```

## Deploy

Production is `jollybuoy.com` on Netlify. Push to `main` or run:

```bash
npm run build
npx netlify deploy --prod
```
